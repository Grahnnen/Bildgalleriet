# Overview

Bildgalleriet is a web-based image gallery built using vanilla JavaScript, HTML and CSS.
The project was developed as part of system development studies with focus on code quality, testing and performance.

The application loads image metadata from a static JSON file and allows users to filter images by category, tags and search queries.

## Features

Thumbnail gallery with full image viewer

Lazy loading and async image decoding

Category tab filtering

Tag-based filtering (AND logic)

Dynamic tag suggestions

Search across title, category and tags

JSON data validation

Unit testing with Jest

CI pipeline using GitHub Actions

Coverage reporting using Codecov
